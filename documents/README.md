# Documents

This repository contains only maintained project documentation. Internal PDF and DOCX source material remains in the local `source/` directory and is excluded from Git tracking and public distribution.

## `project/`

- `project-overview.md` describes the project scope, MVP boundaries, current state, and recommended next steps.
- `architecture.md` defines system boundaries, request flow, integration points, security, and operational decisions.
- `integration-guide.md` defines module ownership, provider handoffs, and integration review checks.
- `requirements-traceability.md` maps requirements to implementation and outstanding acceptance evidence.
- `decisions/` records the architectural decisions that constrain implementation across modules.

Before pushing to GitHub, confirm that the repository contains only project and technical documentation approved for public distribution.
